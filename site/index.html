ρ

A small, hand-forged systems language

Statically typed. Reference-counted, with no garbage collector and no use-after-free. Integer overflow wraps, slices are bounds-checked — zero undefined behavior. The compiler emits machine code and WebAssembly itself, and the same source always compiles to byte-identical output.

// Algebraic data, exhaustively matched.
enum Shape {
  Circle(f64),
  Rect { w: f64, h: f64 },
}

fn area(s: Shape) -> f64 {
  return match s {
    Shape.Circle(r) => 3.14159 * r * r,
    Shape.Rect { w, h } => w * h,
  };
}

// Closures capture by copy.
fn make_adder(n: i32) -> fn(i32) -> i32 {
  return fn(x: i32) -> i32 { return x + n; };
}

// Heap objects are reference-counted: freed the
// moment the last reference dies. No GC, no pauses.
struct Node {
  value: i32,
  next: *Node,
}

fn main() -> i32 {
  printf("{}\n", area(Shape.Rect(w: 3.0, h: 4.0)));
  printf("{}\n", area(Shape.Circle(2.0)));

  let add10: fn(i32) -> i32 = make_adder(10);
  printf("{}\n", add10(5));

  let a: *Node = new Node { value: 1, next: null };
  let b: *Node = a; // one copy, one retain
  printf("{}\n", b.value);
  return 0;
}

Why rho

One binary toolchainbuild, run, test, fmt, check — no build system, no headers, no ceremony.
Direct codegenamd64, arm64 and wasm32 emitted by the compiler. No LLVM.
Reference countingdeterministic cleanup, weak refs for cycles, zero GC pauses.
Determinismsame source, same compiler → byte-identical binaries. Tested, not promised.

Build it in a minute

The whole toolchain is one C program. A C compiler and make are the only requirements to build it:

sh
$ git clone https://github.com/ningh-o/rho
$ cd rho
$ make build/rho-boot
$ echo 'fn main() -> i32 {
    printf("hello, world\n");
    return 0;
  }' > hello.rho
$ ./build/rho-boot build hello.rho
built a.wasm
$ ./build/rho-boot run hello.rho
hello, world

One binary does everything — rho build emits a runnable wasm32-wasi module by default (native targets emit assembly for the platform toolchain to assemble), rho run and rho test execute through any WASI runtime, and rho fmt / rho check need nothing at all. The full story — the memory model, the SSA IR, the bootstrap plan — is in the language specification.
