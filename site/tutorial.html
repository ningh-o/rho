The tutorial

Fourteen chapters from hello world to the memory model. Every example below is compiled and executed by the real compiler — the same binary the playground runs — so nothing here can quietly rot.

01Hello, rho

A rho program is a set of functions; execution starts at main. Types are written after a colon, the return type after ->, and every statement ends with a semicolon. printf comes from the prelude — the standard library that every program imports implicitly.

02Numbers that stay defined

rho has signed and unsigned integers from i8 to i64, IEEE-754 floats, and bool. There is no undefined behavior: integer overflow wraps in two's complement. Literals can carry _ separators and come in decimal, hex and binary. An unsuffixed integer literal adapts to its context and defaults to i32; float literals default to f64.

03let and mut

Bindings are immutable by default; writing to one requires let mut. Shadowing an outer name is an error, and assignment is a statement, not an expression — = and == can never be confused.

04Control flow

Conditions must be bool — there is no truthiness. if is an expression, so it yields a value; while and loop are statements, and break/continue target the innermost loop.

05Functions and recursion

Arguments are passed by value; parameters are mutable local copies. Declaration order does not matter, and recursion is ordinary. A method is just a function whose first parameter is named self — it is then callable with dot syntax.

06Structs on the heap

new allocates a struct on the heap with a reference count of one. A value of type *Point is an owning reference: copying it bumps the count, and when the count reaches zero the object is freed — deterministically, right there, no garbage collector.

07Enums and match

Enum variants can be unit, tuple-like, or struct-like. match destructures payloads into bindings, is itself an expression, and is exhaustiveness-checked — a match that forgets a variant does not compile.

08Slices, safely

make([]T, n) allocates a zeroed, owned array. A slice is a view carrying its own length; indexing is bounds-checked and slicing with [i..j] shares the buffer. Out-of-range access panics with the index and length — it never reads memory it should not.

09Result, Option and ?

Errors are values. A function that can fail returns Result[T, E]; an absent value returns Option[T]. The ? operator unwraps the happy path and returns the error early — explicit, but without the ceremony.

10Closures

Functions are values. A closure captures what it uses from the enclosing scope — immutable bindings by copy, mutable ones by shared box — and static functions and closures share one call syntax.

11Generics

Functions and types can take type parameters. Instantiation is implicit and monomorphizing: each distinct concrete use compiles a specialized copy, verified per instantiation. Trait bounds constrain what a generic body may assume — it can use only the operations its bounds supply.

12defer

defer schedules a statement to run when the enclosing scope exits — on every path, including return, break and continue. Defers in one scope run in reverse order.

13Ownership you can hold

Every heap object carries {rc, wrc, drop}. The compiler inserts retain/release around each copy and destruction — the rule is uniform: each copy takes one retain, each destruction one release. When a count reaches zero the drop glue runs immediately. Cycles are broken with weak[T]; a weak reference observes death instead of preventing it, and w.get() returns null once the object is gone.

14The toolchain

One binary does everything:

  • rho build main.rho — emit a runnable wasm32-wasi module (the default); --set name=value overrides a root const (a build parameter the whole program sees); --target arm64-mac / amd64-linux / amd64-mac emit assembly for the platform toolchain instead
  • rho run main.rho — build and execute (wasm32-wasi, via any WASI runtime)
  • rho test — compile and run every corpus program (wasm32-wasi, via a WASI runtime)
  • rho fmt — canonical formatting; one style, no configuration
  • rho check — type-check only

Determinism is a tested invariant: compiling the same source twice yields byte-identical output — and the playground you used above runs this exact compiler compiled to WebAssembly, producing exactly the bytes the native toolchain produces.

The full story — the memory model, the SSA IR, the bootstrap plan — is in the language specification.
