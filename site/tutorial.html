The tutorial

Seventeen chapters from hello world to the memory model. Every example below is compiled and executed by the real compiler — the same binary the playground runs — and the same programs are pinned against the native toolchain on every test run, so nothing here can quietly rot. Edit anything; Run recompiles.

01Hello, rho

A program is a tree of modules; main.rho is the entry, and main returns the exit code. printf takes a literal format string — every {} is checked at compile time, and a count mismatch is refused before anything runs.

02Numbers that stay defined

Integers are two's complement and wrap — adding one to the biggest i32 gives the smallest, deterministically, on every platform. There is no undefined behavior to optimize around. Float literals that would round to infinity are compile errors, never silent inf.

03let and mut

Bindings are immutable by default; mut is the one write switch, and the compiler holds you to it — assigning through a binding without mut is refused with a pointed diagnostic, not a warning.

04Control flow

if is an expression (both arms produce a value), while and loop are the loops, and break/continue take optional labels when nesting gets deep. Conditions are bool — there is no truthiness.

05Functions and recursion

Functions are declared with fn, and recursion just works — deep recursion ends in a defined panic: stack overflow (exit 101), never a raw trap.

06Structs on the heap

new allocates a zeroed, reference-counted object. A function whose first parameter is self is a method, and a to_str method makes the type printable — the {} hole calls it for you.

07Enums and match

Enums are tagged unions — tuple payloads or named fields, either spelling constructs. match must be exhaustive: a match that misses a variant is a compile error, not a runtime surprise. Payload binders arrive already typed.

08Slices, safely

make([]T, n) allocates a zeroed slice; a..b slices share the buffer. Every index is bounds-checked — the bad one panics with index out of bounds, it never reads neighboring memory. Writing through a slice needs let mut on the binding.

09Result, Option and ?

There are two absence types and no null: Option[T] (spelled ?T) for maybe-missing values, Result[T, E] for recoverable errors. The ? operator propagates early; match consumes. Panics are for programmer bugs — no catch, ever.

10Closures

An anonymous fn is a value like any other; it captures its locals by copy. A mut value can't be captured two ways at once — the compiler refuses the ambiguity — but a mut handle shares its heap object just fine.

11Generics, monomorphized

Type parameters ride square brackets — on functions, structs and call sites. Each instantiation specializes: an i32 use and an i64 use compile to separate, exact code.

12Traits and dyn

A trait declares methods; impl Trait for Type satisfies it. A []dyn Trait holds mixed implementations behind one interface — dispatch through a vtable, the dynamic escape hatch next to the monomorphized default.

13Variadic functions

A last parameter spelled ns: T... accepts any number of arguments and reads as a []T inside. The xs... spread passes a whole slice where the variadic goes — how printf itself takes its values.

14defer runs on every exit

defer schedules its action for the enclosing scope's exit — every exit path (return, break, the end of the block), LIFO across defers. The one exception is a panic: there is no unwinding to run it through.

15Input: read_line

Input lives in std.io, imported by dot path. io.read_line() returns Result[?string, IoError] — both absence layers at once, and match peels them. Press Run and type into the terminal row that appears.

16Ownership you can hold

Every heap object carries a reference count. Copying the pointer bumps it; the last reference dying frees the object — deterministically, no garbage collector, no pauses, no use-after-free. Weak references observe death without keeping anything alive.

17The toolchain

One binary, five verbs. rho build emits a wasm32-wasi module; rho run executes in-process; rho fmt prints the canonical form — its own output re-parses byte-for-byte identically; rho check is the diagnostics face the editor squiggles ride; rho test runs test "name" { … } blocks, whose asserts are the judging law.

And the compiler itself: libs/compiler is rho written in rho, built by the C seed (boot), and graded against boot across the whole corpus on every change. Determinism is a tested invariant: the same source through the same compiler yields byte-identical output, and a pinned canary in the repo fails the gate the day that drifts. The playground you used above runs this exact self-hosted compiler, cross-compiled to WebAssembly.

The full story — the memory model, the counting law, the panic catalog, the conformance map — is in the language specification.
